## Project Steps

1. **Set up the repo:** public repository, README template, labels, Discussions enabled
2. **Pick a topic:** discuss and decide in GitHub Discussions
3. **Create Issues:** one per task, each with a clear title, description, label, and assignee
4. **Research:** commit notes with credible sources
5. **Write the script:** five segments, one per member
6. **Make visuals:** slides or screen recordings, if used
7. **Record:** each member records their own segment in their real voice (no AI voices)
8. **Edit and upload:** combine into one video of 2:30-3:00 and upload to YouTube as **public**
9. **Finish the README:** names, student numbers, topic summary, video link, member roles
10. **Final check:** everything committed, all PRs merged, checklist complete

## Workflow Rules

- All work is done on **branches** (e.g. `research-impact`, `script-segment-3`, `slide-design`, `video-edit`)
- Nothing is committed directly to `main`
- Branches are merged through **Pull Requests** with a written description
- Every PR is **reviewed and commented on by a teammate** before merging
- Issues are **closed with a reference** to the resolving commit or PR
- Commit messages say **what changed and why**
- Team decisions and check-ins go in **GitHub Discussions**
